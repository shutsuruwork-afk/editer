# 配色メモ（Claude 風・未適用）

あとで `index.html` の `:root` にある CSS 変数へ差し替える予定の配色です。
Anthropic のブランドカラーと Claude アプリの見た目に合わせています。
個人用なので配色は寄せてよいが、Claude のロゴ・名前は入れない（公式アプリに見せない）。

## 方針

- 全体は生成り（暖かいオフホワイト）と墨色。色はほとんど使わない
- **オレンジは「主役の操作」だけ**に使う（Claude アプリの送信ボタンと同じ扱い）。多用しない
- 選択中・押されている状態は、色ではなく**薄いグレーの面＋濃い文字**で表す（アプリのサイドバーの選択表示と同じ）
- 警告・削除はオレンジと混ざらないよう、**別の赤**を使う

## 変数と値

| 変数 | 使い道 | ライト | ダーク |
|---|---|---|---|
| `--paper` | 画面の背景、パネル・目次・ポップオーバーの面 | `#faf9f5` | `#141413` |
| `--sheet` | 本文の面、入力欄の中、押されたセグメントボタン | `#ffffff` | `#1f1e1d` |
| `--hover` | ボタンのホバー、セグメントの溝、選択中の項目の面 | `#f0eee6` | `#2b2a27` |
| `--ink` | 本文・UI の文字 | `#141413` | `#faf9f5` |
| `--ink-soft` | 補助の文字（パンくず、字数、アイコン） | `#6b6a64` | `#b0aea5` |
| `--rule` | 区切り線、枠線、進捗バーの溝 | `#e8e6dc` | `#3a3935` |
| `--accent` | 主役の操作（主ボタン）、フォーカスの枠、目標の進捗線 | `#d97757` | `#d97757` |
| `--accent-ink` | アクセント色の**文字**（リンク、選択範囲の字数など） | `#c15f3c` | `#e08a6d` |
| `--accent-soft` | 検索ヒットの色付け、選択中の目次項目 | `#f5e3da` | `#3a2a23` |
| `--info` | 2つめのアクセント（AI 検索の表示、補足情報） | `#6a9bcc` | `#8fb4dc` |
| `--ok` | 保存済みの点、目標達成、成功のお知らせ | `#788c5d` | `#9cb07f` |
| `--danger` | 保存の警告、削除ボタン、確認の枠 | `#b53333` | `#e06c6c` |
| `--danger-soft` | 確認の枠の背景 | `#f7e1e1` | `#3b2222` |

## いまの変数からの置き換え

いまの `index.html` は青（`--ai`）を選択・フォーカスの色に、朱（`--shu`）を警告に使っている。

| いま | 置き換え先 | 備考 |
|---|---|---|
| `--paper` `--sheet` `--hover` `--ink` `--ink-soft` `--rule` `--ok` | 同名のまま値だけ変更 | |
| `--ai`（フォーカスの枠、進捗線） | `--accent` | |
| `--ai`（押されたボタン・選択中の文字色） | `--ink` | 選択はグレーの面で表す |
| `--ai-soft`（押されたボタン・選択中の背景） | `--hover` | 同上 |
| `--ai`（選択範囲の字数など、色付きの文字） | `--accent-ink` | |
| `--shu` / `--shu-soft` | `--danger` / `--danger-soft` | 検索ヒットの `mark` だけは `--accent-soft` |
| 影の色 `rgb(10 20 40 / …)` | `rgb(20 20 19 / …)` | 青みを抜く |

## 注意

- `#d97757` は明るい背景の上だと文字としては薄い（コントラスト約 3:1）。文字に使うときは `--accent-ink` を使う
- オレンジのボタンの上の文字は白（`#ffffff`）
- フォントを寄せる場合、見出し Poppins・本文 Lora。どちらも日本語を持たないので、日本語は既存の明朝・ゴシックにフォールバックさせる
