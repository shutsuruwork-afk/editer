# editer
軽量かつ多機能、使いやすさの総取りを目指したエディタ。個人用

## 原稿帳（日本語小説エディタ）

ブラウザで動く、日本語の小説を書くためのエディタです。`index.html` をブラウザで開くだけで使えます（インストール不要）。

### 画面

画面のほとんどを本文に使い、操作は上の細いバー1本にまとめています。

| 場所 | 中身 |
| --- | --- |
| ☰（左上） | 作品タイトル、章の一覧・追加・並べ替え・削除、作品全体の字数 |
| 章タイトル | そのまま書き換え可能 |
| ルビ／傍点／――／…… | 入力補助 |
| 縦／横、プレビュー、検索 | よく使う切り替え |
| 字数（右上） | 押すと章・作品全体の字数、原稿用紙換算、目標文字数、保存先を表示 |
| ⋯（右上） | 表記チェック、表示設定、書き出し・読み込み、全画面表示 |

入力を始めると上のバーが薄くなり、マウスを動かすと戻ります（設定で切り替え可能。タッチ操作の端末では薄くなりません）。

### できること

- **縦書き／横書き**：1行の字数・文字サイズ・行間・書体（明朝／ゴシック）を変更できます。縦書きではマウスホイールで横にスクロールします
- **ルビ・傍点**：小説投稿サイトと同じ記法です。プレビューで仕上がりを確認できます
  - `｜親文字《おやもじ》`、漢字だけなら `漢字《かんじ》`
  - `《《傍点》》`
  - 漢字を入力した直後に「ルビ」を押すと `《》` が入り、そのまま読みを入力できます
  - 縦書きプレビューでは半角数字や `!?` を縦中横で表示します
- **文字数**：章ごと・作品全体（空白・改行・ルビは数えない）、原稿用紙（400字詰め）換算、選択範囲の字数。目標文字数までの進み具合をバーの下に細い線で表示します
- **自動字下げ**：改行すると段落頭に全角スペースが入ります（かぎかっこで始まる段落には入りません）
- **表記チェック**：三点リーダー・ダッシュの数、！？の後の空白、閉じかっこ前の句点、段落頭の字下げ、かぎかっこの対応
- **章の管理**：章ごとにカーソル位置を覚えます。削除は直後なら「元に戻す」で取り消せます
- **検索・置換**：ほかの章で見つかった件数も表示します
- **保存**：自動保存です。`.txt`（ルビ記法のまま）／`.json` バックアップの書き出しと読み込みができます。Shift_JIS のテキストも読み込めます

### キー操作

| キー | 動作 |
| --- | --- |
| Enter | 改行して字下げ |
| Shift + Enter | 字下げせずに改行 |
| Ctrl/⌘ + F | 検索・置換 |
| Ctrl/⌘ + G（または F3） | 次を検索（Shift で前） |
| Ctrl/⌘ + S | 今すぐ保存 |
| Esc | 開いているものを閉じる |

検索で該当箇所に移動した直後は、Enter で次の該当箇所へ進みます（選択中の文字は上書きされません）。

### 保存について

ローカルで開いた場合、原稿はそのブラウザの localStorage に保存されます。ブラウザのデータを消すと失われるため、⋯ メニューの「書き出し・読み込み」からときどきバックアップを書き出してください。
