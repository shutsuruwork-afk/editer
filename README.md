# editer
軽量かつ多機能、使いやすさの総取りを目指したエディタ。個人用

## 原稿帳（日本語小説エディタ）

ブラウザで動く、日本語の小説を書くためのエディタです。`index.html` をブラウザで開くだけで使えます（インストール不要）。

### できること

- **縦書き／横書き** の切り替え。1行の字数・文字サイズ・行間・書体（明朝／ゴシック）を変更可能
- **ルビ・傍点**：小説投稿サイトと同じ記法に対応し、プレビューで表示
  - `｜親文字《おやもじ》`、漢字だけなら `漢字《かんじ》`
  - `《《傍点》》`
  - 縦書きプレビューでは半角数字や `!?` を縦中横で表示
- **文字数カウント**：章ごと・作品合計（空白・改行・ルビは数えない）、**原稿用紙（400字詰め）換算**、選択範囲の字数、章ごとの目標文字数
- **自動字下げ**：改行すると段落頭に全角スペースを入れる（かぎかっこで始まる段落は字下げしない）
- **入力補助**：ルビ、傍点、――、……、「」、『』をボタンで挿入
- **表記チェック**：三点リーダー・ダッシュの数、！？の後の空白、閉じかっこ前の句点、段落頭の字下げ、かぎかっこの対応
- **章の管理**：追加・並べ替え・削除
- **検索・置換**（ほかの章のヒット件数も表示）
- **自動保存**（ブラウザの localStorage）。`.txt`（ルビ記法のまま）／`.json` バックアップの書き出しと読み込み。Shift_JIS のテキストも読み込めます

### ショートカット

| キー | 動作 |
| --- | --- |
| Enter | 改行して字下げ |
| Shift + Enter | 字下げせずに改行 |
| Ctrl/⌘ + S | 今すぐ保存 |
| Ctrl/⌘ + F | 検索・置換 |
| Esc | パネルを閉じる |

### 保存について

ローカルで開いた場合、原稿はそのブラウザの localStorage に保存されます。ブラウザのデータを消すと失われるため、「書き出し・読み込み」からときどきバックアップを書き出してください。
