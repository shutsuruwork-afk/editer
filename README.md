# editer
軽量かつ多機能、使いやすさの総取りを目指したエディタ。個人用

## 原稿帳（日本語小説エディタ）

ブラウザで動く、日本語の小説を書くためのエディタです。`index.html` をブラウザで開くだけで使えます（インストール不要）。

### 画面

画面のほとんどを本文に使い、操作は上の細いバー1本にまとめています。

| 場所 | 中身 |
| --- | --- |
| ☰（左上） | 作品タイトルと目次。目次は見出しから自動で作られ、押すとその章へ移動します |
| 章の位置（☰ の右） | いま書いている場所の見出し（例：第一章 › 一）。押すと目次が開きます |
| 本文 ▾ | 段落の種類。本文・大見出し・中見出し・小見出しを切り替えます |
| ルビ／傍点／――／…… | 入力補助 |
| 縦／横、プレビュー、検索 | よく使う切り替え |
| 字数（右上） | いまの章の字数。押すと作品全体の字数、原稿用紙換算、目標文字数、保存先を表示 |
| ⋯（右上） | 表記チェック、表示設定、書き出し・読み込み、全画面表示 |

入力を始めると上のバーが薄くなり、マウスを動かすと戻ります（設定で切り替え可能。タッチ操作の端末では薄くなりません）。

### スマホでは

- **入力補助は上のバーの2段目**：「本文 ▾」・ルビ・傍点・――・……と、元に戻す・やり直すが並びます。書いている間は右端に「キーボードを閉じる」ボタンも出ます。幅の狭い機種では入力補助を横にスクロールでき、元に戻す・やり直す・キーボードを閉じるは右端に残ります
- **書いている間は本文をキーボードの上に収める**：キーボードを開くと、本文の欄をキーボードのすぐ上までに縮めます。アプリの中などでキーボードの位置がページから分からないときは目安の高さになるので、本文の下に出る細いつまみを上下にドラッグして合わせてください（その端末で覚えます）
- **iPhone の縦書きのカーソル**：iPhone 標準のカーソルは縦書きで正しい向きに出ないため、文字の下に横線のカーソルを描いて表示します
- 入力や削除のたびに段落を作り直さないので、カーソルの位置や変換中の文字が乱れにくくなっています
- 検索は上のバーの虫めがね、縦書き・横書きの切り替えとプレビューは ⋯ メニューにあります。プレビュー中は画面下の「プレビューを終了」で戻れます
- 保存や置換などのお知らせは、キーボードに隠れないよう画面の上に出ます
- 表記チェックの項目を押すと、一覧を閉じて該当箇所に色を付けて表示します。「一覧に戻る」ですぐ戻れます
- 目次は左へ、下から出るパネルは下へスワイプすると閉じます
- 目次からの移動、検索を閉じたとき、元に戻すなどで勝手にキーボードが開くことはありません
- 文字の大きさは 16px 以上になります（iPhone で入力欄が自動で拡大されるのを防ぐため）

### 見出しと章

原稿は1つの文書で、見出しが章の区切りになります。

- 行を選んで「本文 ▾」から **大見出し・中見出し・小見出し** を選ぶと、その行が見出しになり、本文より大きく表示されます（例：大見出し＝章、中見出し＝話、小見出し＝場面）
- 見出しは ☰ の目次に階層つきで並び、それぞれの字数も表示されます。章の追加や並べ替えは、見出しを書いたり本文ごと切り取って貼り付けたりするだけです
- 行頭で `# `（半角の # と空白）と打つと大見出し、`## ` で中見出し、`### ` で小見出しになります
- 字数は本文だけを数えます（見出しは数えません）

### 保存形式（Markdown）

原稿は内部で Markdown として保存しています。1行が1段落で、見出しは行頭の `#` で表します。

```markdown
# 第一章　雨の古書店
## 一
　駅前の商店街を抜けた先に、その古書店はあった。
「いらっしゃい」
```

「書き出し・読み込み」から、この形式のまま `.md` で書き出し・読み込みできます。

### できること

- **縦書き／横書き**：1行の字数・文字サイズ・行間・書体（明朝／ゴシック）を変更できます。縦書きではマウスホイールで横にスクロールします
- **ルビ・傍点**：小説投稿サイトと同じ記法です。プレビューで仕上がりを確認できます
  - `｜親文字《おやもじ》`、漢字だけなら `漢字《かんじ》`
  - `《《傍点》》`
  - 漢字を入力した直後に「ルビ」を押すと `《》` が入り、そのまま読みを入力できます。読みを入れたら、もう一度「ルビ」を押すか改行すると `》` の後ろに出て続きを書けます（傍点も同じ）
  - 縦書きプレビューでは半角数字や `!?` を縦中横で表示します
- **文字数**：いまの章・作品全体の字数、原稿用紙（400字詰め）換算、選択範囲の字数。目標文字数までの進み具合をバーの下に細い線で表示します
- **自動字下げ**：改行すると段落頭に全角スペースが入ります（かぎかっこで始まる段落には入りません）
- **表記チェック**：三点リーダー・ダッシュの数、！？の後の空白、閉じかっこ前の句点、段落頭の字下げ、かぎかっこの対応。該当箇所は本文に色が付きます
- **検索・置換**：一致した箇所すべてに色が付き、検索欄から手を離さずに Enter で次へ進めます
- **元に戻す／やり直す**：見出しの切り替えや置換もまとめて戻せます
- **書き出し・読み込み**：`.md`（原稿全体）、`.txt`、「この章の本文をコピー」（投稿サイトに1話ずつ貼るとき用）。`.txt` は大見出し付きで末尾に追加します。Shift_JIS のテキストや、以前の版の `.json` バックアップも読み込めます

### キー操作

| キー | 動作 |
| --- | --- |
| Enter | 改行して字下げ |
| Shift + Enter | 字下げせずに改行 |
| Ctrl/⌘ + Alt + 1〜3 | 大・中・小見出し |
| Ctrl/⌘ + Alt + 0 | 本文に戻す |
| Ctrl/⌘ + Z | 元に戻す（Shift を押しながらでやり直す） |
| Ctrl/⌘ + F | 検索・置換 |
| Ctrl/⌘ + G（または F3） | 次を検索（Shift で前） |
| Ctrl/⌘ + S | 今すぐ保存 |
| Esc | 開いているものを閉じる |

### 保存について

ローカルで開いた場合、原稿はそのブラウザの localStorage に保存されます。ブラウザのデータを消すと失われるため、⋯ メニューの「書き出し・読み込み」からときどき `.md` を書き出してください。以前の版（章ごとに保存していた形式）のデータは、開いたときに自動で見出し付きの1つの原稿に変換されます（各章は大見出しになります）。
