# editer
軽量かつ多機能、使いやすさの総取りを目指したエディタ。個人用

ブラウザで動く文書エディタです。`index.html` をブラウザで開くだけで使えます（インストール不要・1ファイル）。
Google ドキュメントのような書式付きの文書を、複数作って切り替えながら書けます。

## できること

### 文字と段落
- **文字の書式**：太字・斜体・下線・取り消し線・上付き・下付き・文字の色・蛍光ペン・フォント（ゴシック／明朝／等幅）・フォントサイズ（8〜96pt、−／＋ボタン）・リンク・コード
- **段落**：標準テキスト・見出し 1〜4・コード、左／中央／右／両端揃え、行間隔（1／1.15／1.5／2）、インデント、引用
- **リスト**：箇条書き（●○■–）・番号付き（1. a. A. i. I. 一、）・チェックリスト、番号の振り直し・開始番号の指定
- **書式のコピー**：ペイントボタン（ダブルクリックで続けて適用）、Ctrl+Alt+C／V
- **書式をクリア**（Ctrl+\）

### 挿入
- **表**：大きさを選んで挿入、行・列の追加と削除、セルの結合と解除、見出し行、セルの背景色、列幅のドラッグ・均等化、最後のセルで Tab を押すと行を追加
- **画像**：端末から・URL・貼り付け・ドラッグ＆ドロップ。大きさ（つまみ／小・中・大・全幅）、左・中央・右寄せ、代替テキスト
- **区切り線・改ページ（Ctrl+Enter）・脚注（Ctrl+Alt+F）・目次（見出しから自動更新）・今日の日付**

### 文書
- **複数の文書**：☰ から一覧・新規作成・コピー・スター・並べ替え（更新順／作成順／名前順）
- **検索**：一覧の検索欄でタイトルと**本文**を横断して探せます（見つかった箇所を表示）
- **ゴミ箱**：削除した文書はゴミ箱へ（すぐに「元に戻す」も可）。30 日後に自動で完全削除
- **変更履歴**：10 分ごとと、文書を開いて最初に保存する前に自動で版を残します。版の表示・復元・コピー・名前付け（「今の版に名前を付ける」）
- **目次**：☰ の「目次」タブに見出しが並び、押すとその場所へ移動
- **検索と置換**：大文字小文字の区別、単語単位、正規表現（置換で `$1` など）
- **文字数**：画面左下に常時表示（設定で切り替え）。⋯ →「文字数」で空白あり／なし・単語数・段落数・原稿用紙換算・脚注数・選択範囲
- **ダウンロード**：Microsoft Word（.docx）・Markdown（.md）・Web ページ（.html）・テキスト（.txt）・印刷／PDF（用紙・余白・ページ番号を設定可）
- **ファイルを開く**：Word（.docx）・Markdown・テキスト（Shift_JIS も可）・HTML
- **貼り付け**：Google ドキュメントや Word、Web ページからの貼り付けで書式・リスト・表・リンク・文字サイズ・改ページを保持。Ctrl+Shift+V で書式なし
- **閲覧モード**：編集せずに読む（スマホでキーボードが開かない）
- **表示設定**：ゴシック／明朝、文字の大きさ、標準の行間、ページ幅（用紙・広め・全幅）、ライト／ダーク、スペルチェック
- **キーボード ショートカット一覧**：Ctrl+/（Mac は ⌘/）

### 入力しながら書式を付ける（Markdown 風）

| 入力 | 結果 |
| --- | --- |
| 行頭で `# ` 〜 `#### ` | 見出し 1〜4 |
| 行頭で `- ` / `* ` / `・` + 空白 | 箇条書き |
| 行頭で `1. ` | 番号付きリスト |
| 行頭で `[] ` | チェックリスト |
| 行頭で `> ` | 引用 |
| 行頭で ```` ``` ```` | コード |
| `---` だけの行 | 区切り線 |
| `**太字**` `*斜体*` `~~取り消し~~` `` `コード` `` | それぞれの書式 |
| URL のあとに空白 | リンク |

直後に Backspace を押すと、自動で付いた書式を取り消せます。

## 保存のしくみ

すべてこのブラウザの中（IndexedDB）に保存され、外部には送られません。

- **自動保存**：入力が止まって 0.8 秒後。書き続けていても 5 秒ごとに必ず保存します。タブを閉じる・切り替えるときにも保存します。失敗したときは間隔を空けて自動でやり直し、容量不足ならその旨を表示します
- **画像**：文書の中に埋め込まず、画像ごとに 1 回だけ保存して参照します（同じ画像を何度使っても容量は 1 つ分。保存が軽く、コピーや変更履歴とも共有）。使われなくなった画像は自動で片付けます
- **変更履歴**：版は圧縮して保存し、名前を付けた版はすべて、それ以外は新しい 40 版と、それより前は 1 日 1 版（60 日分）を残します
- **複数のタブ**：同じ文書を別のタブで開いていても、編集していない側は自動で最新になります。両方で同時に編集した場合も、後から保存した側の内容で保存し、もう一方の内容は変更履歴に残すので失われません
- **壊れたデータ**：読み込めない部分があっても、読める部分を残して修復して開きます
- **消えにくくする**：ブラウザに保存領域を消さないよう頼みます（設定の「保存」から確認・変更できます）
- **バックアップ**：設定 →「バックアップを作成」で、全文書と画像を 1 つのファイルに書き出せます。「バックアップから復元」は既存の文書を上書きしません

以前の「原稿帳」（日本語小説エディタ）の原稿が同じブラウザに残っていれば、初回に 1 つの文書として取り込みます。原稿帳そのものは `feature/genkocho-novel-editor` ブランチに残っています。

## 速さ

長い文書でも重くならないようにしています（約 20 万字・3,000 段落の文書での計測、`npm run perf`）。

- 画面に見えていない段落はレイアウトを省略し、スクロールして見えたときに描画します（開く時間が約 10 分の 1 に）
- 文字数は段落ごとに覚えておき、編集した段落だけ数え直します
- 目次・脚注の一覧も、変わったブロックだけを調べ直します

## 開発

```sh
npm install
npm run build   # src/ → index.html（JS と CSS を 1 ファイルにまとめる）
npm run watch   # src/ の変更を見て自動でビルド
npm test        # ビルドしてブラウザで動作確認（Playwright）
npm run perf    # 長い文書での速さを計測
```

| 場所 | 中身 |
| --- | --- |
| `src/editor/schema.js` | 文書の構造（段落・見出し・リスト・表・画像・脚注・目次、書式）。保存形式なので、項目は追加のみ・名前は変えない |
| `src/editor/commands.js` | 書式・段落・リスト・挿入・リンク・表の操作 |
| `src/editor/keys.js` | キー操作と、入力しながらの自動書式 |
| `src/editor/plugins.js` | 画像・チェックリスト・脚注・目次の表示、貼り付け・ドロップ |
| `src/editor/convert.js` / `docx.js` | Markdown・HTML・テキスト／Word との変換 |
| `src/store.js` | 保存（IndexedDB：文書・検索用テキスト・画像・変更履歴）とタブ間の連絡 |
| `src/app/` | 文書の読み込み・自動保存・版・ゴミ箱（`docs.js`）、画像（`images.js`）、文字数（`text.js`）、設定、バックアップ |
| `src/ui/` | ツールバー・文書一覧・検索・ダイアログ・変更履歴・メニュー |
| `src/styles.css` / `src/index.html` | 見た目と画面の骨組み |
| `docs/colors.md` | 今後適用する配色のメモ |

編集部分は [ProseMirror](https://prosemirror.net/)（MIT）を使っています。
各文書は書字方向の設定（`settings.writingMode`）を持っており、今は横書きのみですが、あとで縦書きを足せるようにしてあります。
