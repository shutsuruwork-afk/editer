# editer
軽量かつ多機能、使いやすさの総取りを目指したエディタ。個人用

ブラウザで動く文書エディタです。`index.html` をブラウザで開くだけで使えます（インストール不要・1ファイル）。
Google ドキュメントのような書式付きの文書を、複数作って切り替えながら書けます。

## できること

- **文字の書式**：太字・斜体・下線・取り消し線・文字の色・蛍光ペン・リンク・インラインコード
- **段落**：標準テキスト・見出し 1〜4・コード、左／中央／右／両端揃え、引用、区切り線
- **リスト**：箇条書き・番号付き・チェックリスト（Tab／Shift+Tab で階層を上下）
- **表**：大きさを選んで挿入、行・列の追加と削除、セルの結合と解除、見出し行、セルの背景色、列幅のドラッグ
- **画像**：ボタン・貼り付け・ドラッグ＆ドロップで挿入。角のつまみか「小・中・大・全幅」で大きさを変更。大きな写真は自動で縮小して保存
- **複数の文書**：☰ から一覧・新規作成・検索・コピー・削除。タイトルが空なら1行目を名前として表示
- **目次**：☰ の「目次」タブに見出しが並び、押すとその場所へ移動
- **検索と置換**：大文字小文字の区別、正規表現（置換で `$1` など）
- **文字数**：画面左下に常時表示（設定で切り替え）。⋯ →「文字数」で空白あり／なし・単語数・段落数・原稿用紙換算・選択範囲
- **書き出し・読み込み**：Markdown（.md）・Web ページ（.html）・テキスト（.txt）。印刷／PDF。Shift_JIS のテキストも読み込めます
- **表示設定**：ゴシック／明朝、文字の大きさ、行間、ページ幅（用紙・広め・全幅）、ライト／ダーク
- **貼り付け**：Google ドキュメントや Web ページからの貼り付けで太字・斜体・リスト・表・リンクなどを保持

### 入力しながら書式を付ける（Markdown 風）

| 入力 | 結果 |
| --- | --- |
| 行頭で `# ` 〜 `#### ` | 見出し 1〜4 |
| 行頭で `- ` / `* ` / `・` + 空白 | 箇条書き |
| 行頭で `1. ` | 番号付きリスト |
| 行頭で `[] ` | チェックリスト |
| 行頭で `> ` | 引用 |
| 行頭で ```` ``` ```` | コード |
| `---` だけの行 | 区切り線 |
| `**太字**` `*斜体*` `~~取り消し~~` `` `コード` `` | それぞれの書式 |
| URL のあとに空白 | リンク |

直後に Backspace を押すと、自動で付いた書式を取り消せます。

### キー操作（Mac は Ctrl → ⌘）

| キー | 動作 |
| --- | --- |
| Ctrl + B / I / U | 太字 / 斜体 / 下線 |
| Ctrl + Shift + X（または Alt + Shift + 5） | 取り消し線 |
| Ctrl + K | リンク（Ctrl を押しながらクリックでリンク先を開く） |
| Ctrl + Alt + 1〜4 / 0 | 見出し 1〜4 / 標準テキスト |
| Ctrl + Shift + 7 / 8 / 9 | 番号付き / 箇条書き / チェックリスト |
| Ctrl + Shift + L / E / R / J | 左 / 中央 / 右 / 両端揃え |
| Ctrl + \\ | 書式をクリア |
| Tab / Shift + Tab | リストの階層、表の次／前のセル |
| Shift + Enter | 段落内で改行 |
| Ctrl + Z / Ctrl + Y（Mac は ⇧⌘Z） | 元に戻す / やり直す |
| Ctrl + F / Ctrl + H | 検索 / 置換 |
| Ctrl + Shift + C | 文字数 |
| Ctrl + S | 今すぐ保存 |
| Esc | 開いているものを閉じる |

## 保存について

文書はこのブラウザの IndexedDB に自動で保存されます。ブラウザのデータを消すと失われるため、大事な文書は ⋯ →「書き出し」でときどき保管してください。
同じ文書を別のタブでも開いている場合、編集していない側は自動で最新の内容に更新されます。

以前の「原稿帳」（日本語小説エディタ）の原稿が同じブラウザに残っていれば、初回に1つの文書として取り込みます（大見出し・中見出し・小見出しは見出し 1〜3 になります。ルビの記法は文字のまま残ります）。
原稿帳そのものは `feature/genkocho-novel-editor` ブランチに残っています。

## 開発

```sh
npm install
npm run build   # src/ → index.html（JS と CSS を1ファイルにまとめる）
npm run watch   # src/ の変更を見て自動でビルド
npm test        # ビルドしてブラウザで動作確認（Playwright）
```

| 場所 | 中身 |
| --- | --- |
| `src/editor/schema.js` | 文書の構造（段落・見出し・リスト・表・画像、書式）。保存形式なので、項目は追加のみ・名前は変えない |
| `src/editor/commands.js` | 書式・段落・リスト・挿入・リンクの操作 |
| `src/editor/keys.js` | キー操作と、入力しながらの自動書式 |
| `src/editor/plugins.js` | 画像とチェックリストの表示、貼り付け・ドロップ |
| `src/editor/convert.js` | Markdown・HTML・テキストとの変換 |
| `src/store.js` | 保存（IndexedDB）とタブ間の連絡 |
| `src/main.js` | 画面（ツールバー・文書一覧・目次・検索・ダイアログ） |
| `src/styles.css` / `src/index.html` | 見た目と画面の骨組み |
| `docs/colors.md` | 今後適用する配色のメモ |

編集部分は [ProseMirror](https://prosemirror.net/)（MIT）を使っています。
各文書は書字方向の設定（`settings.writingMode`）を持っており、今は横書きのみですが、あとで縦書きを足せるようにしてあります。
